# PaintLab

## Запуск

Открыть `PaintLab.sln` в Visual Studio, нажать F5.

## Скриншот

В главной папке имя screenshoot

## Чек-лист

1. Окно. Холст, выбор инструмента, цвета и толщины. Выбранный инструмент виден.

2\. Фигуры. Линия, прямоугольник, эллипс рисуются протягиванием с предпросмотром в любом направлении. Карандаш рисует кривую.

3\. Иерархия. Абстрактный Shape, у каждой фигуры свой Draw. Рисунок рисуется одним циклом без проверки типа фигуры.

4\. Отмена и очистка. Ctrl+Z убирает последнюю фигуру, «Очистить» убирает все. Это методы Drawing.

5\. Файл. Сохранение в JSON и открытие с восстановлением всех фигур, цветов и толщин.

6\. README. Как запустить, скриншот, чек-лист, как устроен проект.

Доп. задания

★ (3 балла). Выделение фигуры щелчком, перемещение мышью, удаление клавишей Delete. Чтобы найти фигуру под курсором, у Shape есть абстрактный метод Contains(point), и каждая фигура реализует его сама: прямоугольник проверяет, что точка внутри, линия проверяет, что точка рядом с отрезком.

★★ (3 балла). Отмена и повтор (Ctrl+Z, Ctrl+Y) через объекты-команды: каждое действие (нарисовать, удалить, очистить) это объект с методами Execute() и Undo(). Экспорт рисунка в PNG.

## Устройство проекта

* `Shape` — абстрактный базовый класс: точки, цвет, толщина, `Draw`, `Contains`, `Move`
* `LineShape`, `RectShape`, `EllipseShape`, `PencilShape` — наследники со своими `Draw` и `Contains`
* `ShapeFactory` — единственное место, где по имени типа создаётся фигура
* `Drawing` — список фигур (композиция): добавить, удалить, очистить, нарисовать, найти под курсором, сохранить, загрузить
* `ShapeDto` — формат фигуры в JSON-файле
* `Commands.cs` — `ICommand`, `AddShapeCommand`, `RemoveShapeCommand`, `ClearCommand`, `History`
* `DrawingSurface` — элемент, который рисует `Drawing`, предпросмотр и рамку выделения
* `MainWindow` — окно, инструменты, мышь, клавиши
